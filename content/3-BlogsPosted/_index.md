### [Blog 1 - MONITORING AND INVESTIGATING S3 SECURITY WITH AWS CLOUDTRAIL AND AMAZON ATHENA](3.1-Blog1/)

**Author:** Dinh Tuan Minh

This blog explains how to build an S3 security investigation system by combining CloudTrail Data Events (which record the identity behind every S3 operation) with Amazon Athena (serverless SQL querying over the logs), enabling quick answers to "who did what" when a security incident occurs.

### [Blog 2 - AMAZON OPENSEARCH SERVICE: IMPROVING ORDER HISTORY SEARCH WITH SEMANTIC SEARCH](3.2-Blog2/)

**Author:** Pham Anh Hao (ITSoldier team member)

This blog analyzes how Amazon upgraded its order history search feature using Semantic Search on Amazon OpenSearch Service and Amazon SageMaker, combined with a Cell-Based Architecture to ensure resilience while processing billions of records.

### [Blog 3 - SIMPLIFYING AWS APPSYNC EVENTS INTEGRATION WITH POWERTOOLS FOR AWS LAMBDA](3.3-Blog3/)

**Author:** Pham Anh Hao (ITSoldier team member)

This blog introduces the `AppSyncEventsResolver` utility in Powertools for AWS Lambda, which automates routing, data normalization, and batch processing for WebSocket events in real-time applications, eliminating most of the boilerplate code.
