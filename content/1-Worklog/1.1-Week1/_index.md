### Lessons Learned:

- When working with the cloud, account security must be prioritized from the start — especially enabling MFA and avoiding root account usage for daily operations.
- Cost governance is an essential skill when learning AWS. Creating budgets and cost alerts helps limit the risk of unexpected costs during practice.
- Learning AWS effectively requires combining cloud architecture theory, hands-on console labs, and process notes to build a practical deployment mindset.
